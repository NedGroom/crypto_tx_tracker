## About
`crypto_tx_tracker` helps investors track cryptocurrency transactions and taxable events by normalizing, tagging, and exporting transaction data for reporting.

## Features
- Transaction import (CSV, API adapters)
- Normalize transactions across exchanges/wallets
- Tagging and categorization of taxable events
- Export reports for tax filing
- Audit trail and review UI
- Investment ROI investigation
